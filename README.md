# William Liu

PhD student working on soft robotics, additive manufacturing (fused granulate fabrication), and autonomous workcells for fabricating and testing soft actuators.

## What I build
- **EvoFab**: a self-driving workflow for soft-robot discovery, covering CAD, process simulation and slicing.
- **Fused granulate fabrication (FGF)**: multi-material pellet printing and process modelling.
- **Somatik Systems**: commercialisation of hardware for soft-material printing.
